Lesson 2

What “agentic” means

2 min

An agent decides its own next step.

Anthropic, the company behind Claude, separates AI systems into two kinds. A workflow follows a path someone coded in advance. An agent decides for itself which steps to take and which tools to use, based on what it finds along the way. Flip each card to compare them with ordinary chat.

Agents trade speed for capability. For a one-line answer, plain chat is still the fastest choice.

Lesson 3

The agentic loop

3 min

Plan → Act → Check → Adjust. Repeat until done.

Every agent, however advanced, runs the same basic loop. Let's follow one real task through it: “Turn last quarter's customer feedback into a one-page summary for my manager.”

↺ Then back to Plan, until the task is done, Claude needs you, or it reaches a limit you set.

Why it matters: the Check step is what makes an agent different from a long chat reply. It catches its own mistakes by looking at real results, rather than assuming each step worked.

Lesson 4

How the loop works in Claude

3.5 min

Anthropic first built this loop into Claude Code, a tool for programmers. When it noticed people using Claude Code for all kinds of non-coding work, it brought the same agent to everyday work: first as a mode called Cowork, and now as part of Claude itself. You describe what you need, and Claude decides whether that's a quick answer or a task. Select each tab to see where the loop shows up.
